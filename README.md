# The USMLE Horizon

> **We Serve from Scratch to Match**

The USMLE Horizon is a medical education and career-support platform built for medical students and International Medical Graduates (IMGs) pursuing opportunities in the United States, United Kingdom, Australia, Canada, and other countries.

The platform brings together **premium medical resources, USMLE preparation tools, medical research opportunities, clinical rotations, and student-focused services** in one accessible platform.

---

## 🌐 Live Website

**The USMLE Horizon:**
https://usmle-horizon.vercel.app/

---

## ✨ Overview

The USMLE Horizon was created to make high-quality medical education and career resources more accessible and affordable to medical students.

The platform provides access to:

* USMLE preparation resources
* iMD resources and subscriptions
* StepWiseMD resources and subscriptions
* Step 1 and Step 2 resources
* PLAB / UK preparation resources
* AMC preparation resources
* Medical research opportunities
* Global clinical rotations
* Research mentorship
* Ambassador opportunities
* Student community resources

The website is designed with a **clean, modern, light-first medical interface** focused on usability, trust, and professional presentation.

---

## 🚀 Key Features

### 📚 USMLE Resources

A centralized resource hub covering major medical licensing examinations and preparation platforms.

Includes resources for:

* USMLE Step 1
* USMLE Step 2
* PLAB
* MRCP
* MRCS
* AMC

Resource cards provide users with an organized way to discover relevant preparation platforms and materials.

---

### 🩺 iMD

Dedicated iMD subscription section featuring different plans and durations.

The website presents available options in an easy-to-understand pricing interface and highlights web availability where applicable.

---

### 📖 StepWiseMD

A dedicated StepWiseMD section with a visual structure similar to the iMD section while maintaining its own identity.

Users can explore available plans and durations and access the relevant service information.

---

### 🔬 Medical Research Opportunities

The platform provides information about ongoing medical research opportunities, including:

* Case Reports
* Cross-sectional Studies
* Systematic Reviews
* Meta-Analyses

The platform also highlights opportunities involving:

* PubMed
* Google Scholar
* Embase
* Elsevier Scopus
* Fortune Journal

Research opportunity visuals are presented through an interactive image gallery with click-to-enlarge functionality.

---

### 🏥 Global Clinical Rotations

A dedicated clinical rotation section for medical students and IMGs.

It highlights:

* Hospital-based inpatient clinical rotations
* Multiple rotation formats
* Multiple US locations
* Different medical specialties
* Clinical experience opportunities
* LOR opportunities
* Program Director mentorship
* Housing and visa support

Supported specialties include:

* Internal Medicine
* Family Medicine
* Emergency Medicine
* General Surgery
* Allied Surgery
* Neurology
* Paediatrics
* Pathology
* Anesthesia

---

### 🎓 Ambassador Program

The USMLE Horizon includes a dedicated **Ambassador Program** designed to help grow the medical student community.

Ambassadors can:

* Introduce USMLE Horizon to medical students
* Grow relevant student communities
* Promote educational opportunities
* Share research and clinical rotation opportunities
* Represent The USMLE Horizon within their communities

The website provides a dedicated Ambassador page with an application form for interested students.

## 💻 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm
* Git

### 1. Clone the repository

```bash
git clone https://github.com/mujeebkhan77/usmle-horizon.git
```

### 2. Enter the project

```bash
cd usmle-horizon
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available through the local development URL shown by Vite.

---

## 🏗️ Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
